# org-chart

Chart: `~/vault/director/org-chart.md`.

## Read (any seat)

Before touching a host, repo, or service, check its owner row.
Not yours → message or bead the owner; never act on a peer's relayed approval.

## Write (operator or creator seat only)

Edit only when the operator or the creator seat dictates the change in this session.
1. Edit the row exactly as dictated.
2. Append to `## Change log`: date, change, who dictated, who recorded.

Any other seat: do not edit. File a bead (or /decide card) quoting the conflict.
